# وب‌سایت هتل

وب‌سایت چندزبانه هتل (فارسی، انگلیسی، آذری) با PHP و MySQL، همراه با پنل مدیریت.

## امکانات
- صفحات عمومی: خانه، اتاق‌ها (با فیلتر قیمت و مرتب‌سازی)، جزئیات اتاق (گالری، ویدیو، نظرات، **درخواست رزرو آنلاین**)، وبلاگ، درباره ما، تماس
- پنل مدیریت (`/admin`): داشبورد، مدیریت رزروها، اتاق‌ها، وبلاگ و نظرات

## نصب (XAMPP / WAMP)
1. پوشه پروژه را در `htdocs` قرار دهید.
2. در phpMyAdmin یک دیتابیس با نام `hotel_db` (charset: `utf8mb4`) بسازید و فایل `config/hotel_db.sql` را Import کنید.
3. در صورت نیاز اطلاعات اتصال را در `config/db.php` تغییر دهید.
4. پنل مدیریت: `http://localhost/<project>/admin/login.php`

### به‌روزرسانی دیتابیس موجود
اگر دیتابیس را قبلاً ساخته‌اید، برای فعال شدن سیستم رزرو فقط فایل `config/bookings.sql` را یک بار اجرا کنید.

## نکات امنیتی
- تمام فرم‌ها و عملیات حذف/تغییر وضعیت با توکن CSRF محافظت می‌شوند.
- فایل‌های آپلودی از نظر محتوای واقعی تصویر بررسی و با نام تصادفی ذخیره می‌شوند؛ اجرای اسکریپت در `uploads/` با `.htaccess` مسدود است.
- دسترسی وب به پوشه `config/` (فایل‌های SQL و تنظیمات) با `.htaccess` بسته شده است.
- در محیط واقعی حتماً رمز کاربر `root` دیتابیس و رمز ادمین را تغییر دهید.
